# Contributing

Thank you for wanting to contribute to NFEEmissorFront! Please follow these guidelines to make collaboration smooth.

1. Bug reports

- Open an issue with a clear title, reproduction steps, expected behavior, and actual behavior.
- Include environment details: Node version, OS, and steps to reproduce.

2. Feature requests

- Describe the user problem, suggested UI/UX, and any API changes needed.
- If possible, include mockups or example payloads.

3. Development workflow

- Fork or branch from `main`.
- Use descriptive branch names: `feat/emit-nfe`, `fix/cert-storage`.
- Run lint and type checks before submitting a PR.

4. Pull requests

- Keep PRs focused and small.
- Add screenshots for UI changes and include test steps.
- Reference related issues (e.g., `Closes #12`).

5. Coding style

- Follow existing TypeScript and React patterns in the repository.
- Prefer explicit typing for public functions and props.

6. Security & secrets

- Never commit private keys, passwords, or certificates.
- Use environment variables or secure stores for secrets.

7. Tests

- Add unit tests for new logic where feasible. If you add tests, document how to run them.

If you need help getting started, open an issue and tag maintainers for guidance.
